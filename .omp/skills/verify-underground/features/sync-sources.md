# Sync source repos to the agent

The owner lists git repos in `~/.local/share/underground/sources`, one `<repo path or ~/path> <target>` per line. At every `omp` launch (`host/bin/ug-agent`) the launcher copies the committed `HEAD` of each repo into `<agent home>/<target>` as the agent, before it opens the ssh session. The target then holds the repo's files and a `.ug-names` list; files that a later commit deletes are removed, and files the agent added itself stay. A bad `sources` line, a missing `sources` file, or a source that cannot be copied stops the launch before ssh with a `ug-agent:` message and exit 1. The agent-side `agent-unpack` helper refuses unsafe targets and empty input on its own.

## Sub-features

- `sync-launch` copies the `HEAD` of each listed repo into the agent home at launch and writes `.ug-names`; top-level `.git*` and `.ug-*` entries and uncommitted files are not copied.
- `sync-prune` removes from the target the files that a new commit deleted and updates changed files at the next launch.
- `sync-keep-extra` keeps files that the agent added to the target.
- `bad-line` refuses a `sources` file with a relative repo path, a `.`/`..`, absolute, duplicate or nested target, a `plugin` line, or a wrong word count, before any copy and before ssh.
- `nogit` refuses a source that is not a git repo with a `HEAD` commit (plain directory, repo without commits, missing path) with `cannot sync ...`, and does not start ssh.
- `nogrant` reports the same `cannot sync ...` message when the agent cannot run the unpack helper.
- `nosources` refuses a launch when the `sources` file is missing.
- `unpack-refuse` makes `agent-unpack` refuse `.`/`..` and absolute targets, a missing argument and an empty archive.
- `unpack-direct` makes `agent-unpack <target>` with a tar on stdin fill the target and write `.ug-names`.

## How to get to it (user POV)

- The owner edits `~/.local/share/underground/sources` (created empty by `host/bin/ug-setup`) and runs `omp` (= `host/bin/ug-agent`), from any directory.
- The agent (or the owner through `sudo -u ugagent`) runs `<root>/code/bin/agent-unpack <target>` with a tar stream on stdin; this is the helper that the launcher calls.

## Driving it with ugv

Preconditions:

- Baseline from [README.md](./README.md): `U=.omp/skills/verify-underground/scripts/ugv`, `RUN=$(date +%Y%m%d-%H%M%S)-sync-sources`, `$U up "$RUN"`, `B=/private/tmp/ugv-$RUN`, and `$U doctor "$RUN"` ends with `doctor: ok`.
- `sources` is empty and `agent-home` has no `agent-config/` or `apps/`. Run the bullets in order; each bullet uses the state of the bullets before it.
- In every launch step, the step's `calls/` show `sudo` with argv `-n -u ugagent $B/root/code/bin/agent-unpack <target>` for each source, and `ssh` only when the step exits 0.

- **Make a source repo.** Create an owner repo with tracked files, top-level `.gitignore` and `.ug-local`, a nested `.gitignore`, and an uncommitted file. Run `$U git "$RUN" -- init -q -b main owner-home/src/notes`, `$U look "$RUN" sync-seed -- sh -c 'cd owner-home/src/notes && mkdir -p skills/review && printf "keep\n" > keep.md && printf "old\n" > old.md && printf "r\n" > skills/review/SKILL.md && printf "n\n" > skills/review/.gitignore && printf "*.tmp\n" > .gitignore && printf "x\n" > .ug-local && printf "draft\n" > draft.md'`, `$U git "$RUN" -- -C owner-home/src/notes add keep.md old.md skills .gitignore .ug-local` and `$U git "$RUN" -- -C owner-home/src/notes commit -qm first`. Each step exits 0.
- **List the source.** Write the `sources` file with a comment, a blank line and one source. Run `$U look "$RUN" sync-sources-file -- sh -c 'printf "# agent config\n\n~/src/notes agent-config/notes\n" > owner-home/.local/share/underground/sources && cat owner-home/.local/share/underground/sources'`. stdout shows the three lines.
- **sync-launch.** Start a session. Run `$U owner "$RUN" --label sync-launch -- host/bin/ug-agent`. Exit 0; stdout `omp-stub: session started in $B/agent-home/scratch`; calls show `sudo: ... argv=-n -u ugagent $B/root/code/bin/agent-unpack agent-config/notes` and one `ssh` call to `ugagent@127.0.0.1`.
- **sync-launch state.** Run `$U look "$RUN" sync-launch-target -- ls -laR agent-home/agent-config/notes` and `$U look "$RUN" sync-launch-names -- cat agent-home/agent-config/notes/.ug-names`. The target holds `.ug-names`, `keep.md`, `old.md` and `skills/review/` with `SKILL.md` and `.gitignore`; it has no `.git`, `.gitignore`, `.ug-local` or `draft.md`. `.ug-names` reads `keep.md`, `old.md`, `skills`.
- **sync-keep-extra.** The agent adds its own file to the target. Run `$U agent "$RUN" --label sync-keep-extra -- sh -c 'printf "mine\n" > agent-config/notes/agent-notes.md'`. Exit 0.
- **sync-prune.** The owner commits a delete and an edit, then launches again. Run `$U git "$RUN" -- -C owner-home/src/notes rm -q old.md`, `$U look "$RUN" sync-prune-edit -- sh -c 'printf "keep v2\n" > owner-home/src/notes/keep.md'`, `$U git "$RUN" -- -C owner-home/src/notes commit -qam "drop old"` and `$U owner "$RUN" --label sync-prune -- host/bin/ug-agent`. The launch exits 0 with the `omp-stub: session started` line.
- **sync-prune and sync-keep-extra state.** Run `$U look "$RUN" sync-prune-target -- sh -c 'ls -la agent-home/agent-config/notes; cat agent-home/agent-config/notes/.ug-names agent-home/agent-config/notes/keep.md agent-home/agent-config/notes/agent-notes.md'`. The listing has `.ug-names`, `agent-notes.md`, `keep.md`, `skills` and no `old.md`; stdout then reads `keep.md`, `skills`, `keep v2`, `mine`. `agent-notes.md` is not in `.ug-names`.
- **bad-line: relative repo path.** Run `$U look "$RUN" bad-relative-write -- sh -c 'printf "src/notes agent-config/notes\n" > owner-home/.local/share/underground/sources'` and `$U owner "$RUN" --label bad-relative -- host/bin/ug-agent`. Exit 1; stderr `ug-agent: in $B/owner-home/.local/share/underground/sources: src/notes is not an absolute path or a ~ path`; calls show only `launchctl`, no `sudo` and no `ssh`.
- **bad-line: `..` target.** Run `$U look "$RUN" bad-dotdot-write -- sh -c 'printf "~/src/notes agent-config/../notes\n" > owner-home/.local/share/underground/sources'` and `$U owner "$RUN" --label bad-dotdot -- host/bin/ug-agent`. Exit 1; stderr `ug-agent: in $B/owner-home/.local/share/underground/sources: target agent-config/../notes has a . or .. component`; no `sudo`, no `ssh`.
- **bad-line: absolute target.** Run `$U look "$RUN" bad-abs-target-write -- sh -c 'printf "~/src/notes /etc/notes\n" > owner-home/.local/share/underground/sources'` and `$U owner "$RUN" --label bad-abs-target -- host/bin/ug-agent`. Exit 1; stderr `ug-agent: in $B/owner-home/.local/share/underground/sources: target /etc/notes is not a plain relative path`; no `sudo`, no `ssh`.
- **bad-line: duplicate target.** Run `$U look "$RUN" bad-duplicate-write -- sh -c 'printf "~/src/notes agent-config/notes\n~/src/other agent-config/notes\n" > owner-home/.local/share/underground/sources'` and `$U owner "$RUN" --label bad-duplicate -- host/bin/ug-agent`. Exit 1; stderr `ug-agent: in $B/owner-home/.local/share/underground/sources: two sources share the target agent-config/notes`; no `sudo`, no `ssh`.
- **bad-line: nested target.** Run `$U look "$RUN" bad-nested-write -- sh -c 'printf "~/src/notes agent-config\n~/src/other agent-config/notes\n" > owner-home/.local/share/underground/sources'` and `$U owner "$RUN" --label bad-nested -- host/bin/ug-agent`. Exit 1; stderr `ug-agent: in $B/owner-home/.local/share/underground/sources: target agent-config/notes lies inside agent-config`; no `sudo` (the valid first line is not copied either), no `ssh`.
- **bad-line: plugin line.** Run `$U look "$RUN" bad-plugin-write -- sh -c 'printf "plugin arkan@arkan\n" > owner-home/.local/share/underground/sources'` and `$U owner "$RUN" --label bad-plugin -- host/bin/ug-agent`. Exit 1; stderr `ug-agent: in $B/owner-home/.local/share/underground/sources: "plugin arkan@arkan": plugins are not sources; they come from omp's own github marketplace`; no `sudo`, no `ssh`.
- **bad-line: word count.** Run `$U look "$RUN" bad-extra-write -- sh -c 'printf "~/src/notes agent-config/notes extra\n" > owner-home/.local/share/underground/sources'` and `$U owner "$RUN" --label bad-extra -- host/bin/ug-agent`, then `$U look "$RUN" bad-missing-target-write -- sh -c 'printf "~/src/notes\n" > owner-home/.local/share/underground/sources'` and `$U owner "$RUN" --label bad-missing-target -- host/bin/ug-agent`. Both exit 1 with stderr `ug-agent: in $B/owner-home/.local/share/underground/sources: "<the line>": a source is a repo path and a target, and nothing else`; no `sudo`, no `ssh`.
- **bad-line state.** Run `$U look "$RUN" bad-line-state -- ls -la agent-home/agent-config/notes`. The listing is the same as in the sync-prune state (`.ug-names`, `agent-notes.md`, `keep.md`, `skills`).
- **nogit: plain directory next to a good source.** Run `$U look "$RUN" nogit-seed -- sh -c 'mkdir -p owner-home/src/plain && printf "p\n" > owner-home/src/plain/a.md && printf "~/src/notes agent-config/notes\n~/src/plain agent-config/plain\n" > owner-home/.local/share/underground/sources'` and `$U owner "$RUN" --label nogit-plain -- host/bin/ug-agent`. Exit 1; stderr has `fatal: not a git repository (or any of the parent directories): .git`, `agent-unpack: refused an empty archive for agent-config/plain, so nothing changed` and `ug-agent: cannot sync $B/owner-home/src/plain to ugagent:agent-config/plain; is it a git repository with a HEAD commit, and did host/bin/ug-setup grant the unpack helper?`; calls show `sudo` for both `agent-config/notes` and `agent-config/plain`, and no `ssh`.
- **nogit: repo without commits.** Run `$U git "$RUN" -- init -q -b main owner-home/src/empty`, `$U look "$RUN" nogit-nohead-write -- sh -c 'printf "~/src/empty agent-config/empty\n" > owner-home/.local/share/underground/sources'` and `$U owner "$RUN" --label nogit-nohead -- host/bin/ug-agent`. Exit 1; stderr `fatal: not a valid object name: HEAD`, `agent-unpack: refused an empty archive for agent-config/empty, so nothing changed` and `ug-agent: cannot sync $B/owner-home/src/empty to ugagent:agent-config/empty; is it a git repository with a HEAD commit, ...`; no `ssh`.
- **nogit: missing path.** Run `$U look "$RUN" nogit-missing-write -- sh -c 'printf "~/src/nowhere agent-config/nowhere\n" > owner-home/.local/share/underground/sources'` and `$U owner "$RUN" --label nogit-missing -- host/bin/ug-agent`. Exit 1; stderr `fatal: cannot change to '$B/owner-home/src/nowhere': No such file or directory` and `ug-agent: cannot sync $B/owner-home/src/nowhere to ugagent:agent-config/nowhere; ...`; no `ssh`.
- **nogit state.** Run `$U look "$RUN" nogit-state -- ls -la agent-home/agent-config agent-home/agent-config/plain agent-home/agent-config/empty`. `agent-config` lists `empty`, `notes`, `nowhere`, `plain`; `plain` and `empty` are empty directories (no `.ug-names`).
- **nogrant.** The `sudo` boundary refuses the unpack helper. Run `$U look "$RUN" nogrant-write -- sh -c 'printf "~/src/notes agent-config/notes\n" > owner-home/.local/share/underground/sources'`, `$U fault "$RUN" sudo 1`, `$U owner "$RUN" --label nogrant -- host/bin/ug-agent` and `$U fault "$RUN" sudo clear`. Exit 1; stderr `ug-agent: cannot sync $B/owner-home/src/notes to ugagent:agent-config/notes; is it a git repository with a HEAD commit, and did host/bin/ug-setup grant the unpack helper?`; calls show `sudo: ... fault sudo: exit 1` and no `ssh`.
- **nosources.** Run `$U look "$RUN" nosources-move -- mv owner-home/.local/share/underground/sources owner-home/.local/share/underground/sources.off` and `$U owner "$RUN" --label nosources -- host/bin/ug-agent`. Exit 1; stderr `ug-agent: no $B/owner-home/.local/share/underground/sources; run: host/bin/ug-setup to create it`; no `sudo`, no `ssh`. Run `$U look "$RUN" nosources-restore -- mv owner-home/.local/share/underground/sources.off owner-home/.local/share/underground/sources` to restore it.
- **unpack-refuse.** Run `$U agent "$RUN" --label unpack-dotdot -- code/bin/agent-unpack ../x </dev/null`, `$U agent "$RUN" --label unpack-dot -- code/bin/agent-unpack a/./b </dev/null`, `$U agent "$RUN" --label unpack-abs -- code/bin/agent-unpack /etc </dev/null`, `$U agent "$RUN" --label unpack-usage -- code/bin/agent-unpack </dev/null` and `$U agent "$RUN" --label unpack-empty -- code/bin/agent-unpack apps/x </dev/null`. They exit 1, 1, 1, 64, 1 with stderr `agent-unpack: refused target ../x: it has a . or .. component`, `agent-unpack: refused target a/./b: it has a . or .. component`, `agent-unpack: refused target /etc: expected a relative path of letters, digits, dots, dashes and underscores`, `usage: agent-unpack <target>` and `agent-unpack: refused an empty archive for apps/x, so nothing changed`.
- **unpack-refuse state.** Run `$U look "$RUN" unpack-refuse-state -- ls -la agent-home agent-home/apps agent-home/apps/x`. `agent-home` has no `x`, `a` or `etc` entry from the refused targets; `apps/x` exists and is empty, and `agent-home` has `.ug-unpack.apps_x.lock` (no lock for the refused targets).
- **unpack-direct.** Run `$U look "$RUN" unpack-direct-tar -- sh -c 'git -C owner-home/src/notes archive --format=tar HEAD > notes.tar'` and `$U agent "$RUN" --label unpack-direct -- code/bin/agent-unpack apps/notes < "$B/notes.tar"`. Exit 0, no output.
- **unpack-direct state.** Run `$U look "$RUN" unpack-direct-state -- sh -c 'ls -la agent-home/apps/notes; cat agent-home/apps/notes/.ug-names'`. The listing has `.ug-names`, `keep.md`, `skills`; `.ug-names` reads `keep.md`, `skills`.
- **Finish.** Run `$U down "$RUN"`. It prints `evidence: <dir>`, and that dir holds `steps/`.

## Gotchas

- The launch checks every `sources` line before it copies anything: one bad line stops all copies. A repo that cannot be copied fails alone: the other sources are still copied, but the launcher exits 1 and ssh does not start.
- A failed copy (`nogit`, `unpack-empty`) still leaves an empty target directory and a `.ug-unpack.<target with / as _>.lock` file in the agent home. Do not read an existing empty target as a sign that a copy ran; check `.ug-names`.
- Only the committed `HEAD` is copied. Uncommitted edits and untracked files (`draft.md`) do not reach the agent until the owner commits.
- Only top-level names that start with `.git` or `.ug-` are dropped; a nested `skills/review/.gitignore` is copied.
- `.ug-names` lists only the top-level names from the repo. Agent files in the target are kept because they are not in it; an agent file with the same name as a repo entry is replaced at the next launch (not driven).
- `ug-agent` reads `sources` relative to the owner `HOME`. A `~/...` path expands to the owner home; `~user` and relative paths are refused.
- `nogrant` is proven only against the `sudo` stub; the real sudoers grant from `ug-setup` is not verified in the stand-in.
- `look` runs with your own environment; use it only for seeding and reading. Paths in `look` are relative to `$B`, in `agent` steps relative to `agent-home`.
